# Create VVVF Simulator · 新岛 Forge 补丁

适用 Minecraft 1.20.1、Create 0.5.1.j、VVVF Simulator Library 1.0.6。上游为 [Deiloproxide/Create-VVVF-Simulator](https://github.com/Deiloproxide/Create-VVVF-Simulator/tree/8b8ff4093d4a075f629db9d196f11f8c81d2c954)，沿用 GPL-3.0。本地派生版为 `1.2.1-niijima.11`（2026-11-28）。

## 玩法

- 新列车及旧存档中未单独设置的列车使用 Create 原声。车主或权限等级 2 及以上的玩家可用 `/列车音色 <音色>` 设置音色，也可用同义命令 `/liecheyinse <音色>` 或 `/vvvf <音色>`。选择 `create` 恢复原声，也可选 `siemens`、`alstom`、`tn27`、`toyodenki`。
- `/列车音色 音量 <0–200>`（拼音 `/liecheyinse yinliang <0–200>`）调整该车整套 VVVF 声音，含电机、设备底噪、风声与起步气声和开关声。默认 100%，按下文的 48 秒短程将四种整套 VVVF 声音分别校准到约 −20 LUFS-I，随列车存档并同步给听者。选择 Create 原声时使用 Create 自身的列车声与音量。
- 坐在车上时选座位所属列车，站立时选已接管的驾驶台。权限按选中的那列车检查。名称写入 Create 的列车存档，通过速度同步包传给客户端。切换音色不会改变速度或加速度配置。
- 牵引基频按 Create 默认加速度 3 格/秒²校准。从静止持续加速时，同样的极速和音色下，加速度调成 1 的列车与加速度为 3 的参考车在相同时间经过相同的音色段。补偿倍率是 3 ÷ 当前配置加速度，普通和动力列车分别取各自的配置。加速度为零时倍率回退为 1。
- 牵引合成器将平滑后的速度占比乘以该倍率，再按配置的最高基频封顶。包内加速度为 1，约在实际极速的三分之一达到 115 Hz，此后更高车速区间内基频保持 115 Hz。风声和列车运动沿用实际速度。test0126 的非线性低速补偿曲线由本规则替代。
- 移除上游 Forge 客户端的全局命令、全局音色偏好读取和自动聊天回显。模组自有同步通道区分上游和派生版，客户端与服务器随包一起更新。

## 构建

1. 签出上面链接的上游提交，在该工作树执行 `git apply --ignore-space-change <本目录绝对路径>/forge.patch`。
2. 在本目录用相邻 `../niijima-test/gradlew.bat` 执行 `assembleForge`，传入以下 Gradle 项目属性。ForgeGradle 使用 Java 17。
   - `-Pupstream=已应用补丁的工作树`
   - `-Poriginal=上游 create_vvvf_simulator-forge-1.2.1.jar`，SHA-1 为 `651a16a5582a14a874dd696f20cebc064e5db750`。
   - `-PvvvfLibrary=vvvf_simulator_lib-forge-1.0.6.jar`
   - `-PmappedCreate=使用 official 1.20.1 映射的 Create 0.5.1.j JAR`
3. 成品在 `build/dist`。整合包从 `pack/overrides/mods` 分发；两服更新源用同名 `.ablink`。

test0126（pack-id 123）已登记到本机启动器。隔离测试覆盖了中文及拼音命令、跨车座位优先、权限、五种音色的存取、原声与粒子路径的切换、四份 YAML 的实际解析和频率曲线。游戏内听感与多人同时收听仍待实测。

## 牵引声响度对照 · 2026-11-28

以 test0126 的实际音频配置调用现有 VVVFSoundGen 和 1.0.6 合成库，使用内置 default.ir、44.1 kHz、4096 帧缓冲、单声道近场增益 1。每套音色均从 0 升至 115 Hz（18.52 秒），巡航 10.96 秒后对称降频。FFmpeg loudnorm 测得的输入响度如下，单位 LUFS。未叠加风声、底噪、其他车辆或空间混响模组。上游 default.yaml 与 siemens.yaml 逐字节相同。

| 音色 | 全程 | 加速 | 115 Hz 巡航 | 制动 | 全程真峰值 dBTP |
| --- | ---: | ---: | ---: | ---: | ---: |
| siemens | −30.37 | −30.35 | −31.35 | −30.16 | −12.40 |
| alstom | −33.48 | −34.94 | −31.35 | −33.95 | −19.42 |
| tn27 | −29.89 | −31.07 | −26.35 | −31.66 | −15.05 |
| toyodenki | −24.02 | −23.32 | −31.35 | −22.91 | −3.71 |

Toyo 相对西门子全程高 6.35 LU，差异集中在加减速。整段固定衰减也会降低原来响度相同的巡航段。这份测量用于比较同一输入下的合成音色；玩家实际听到的响度还取决于距离、车数、环境和游戏音量。

### 整套声音 · test0128

使用 test0126 的客户端实际配置，音量 100%，单车厢近场，近、远场增益均为 1。电机、设备谐波、棕噪和风声按生产生成器合成，按引擎的 16 位限幅和双声道输出混音。起步时叠加游戏资产 random/fizz 和 wooden_trapdoor/close1，均用两倍音高，以实际相对音量 0.6 和 0.36 居中播放。每种工况的四种音色共用同一条随机底噪、风声与起步声。测量为离线立体声 LUFS-I，未模拟车厢叠加、声卡和空间反射。上一张表为单声道电机，两张表适合分别作音色间比较。

| 音色 | 48 秒全程 | 加速 | 匀速 | 制动 | 122.08 秒全程 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Siemens | −26.88 | −26.78 | −27.48 | −26.89 | −26.11 |
| Alstom | −29.34 | −30.25 | −27.48 | −29.91 | −26.81 |

test0128（pack-id 125）的多人牵引频率在原有五样本中值与加速度限幅后再作一阶低通，20 tick/秒时半衰期约 0.33 秒。单人保留原响应。隔离测试以持续三 tick 的异常速度包测得频率最大偏移从 0.978 Hz 降到 0.239 Hz。中英文别名的音量命令、跨车优先级、权限、范围和存档往返均已做隔离验证。已登记本机测试包并更新两服共享更新源，多人游戏内听感仍待实测。

### 轮轨接头试听 · test0130（pack-id 127，1.2.1-niijima.5）

所有行驶中的车厢在客户端按两个二轴转向架播放短击声，包含使用 Create 原声的列车。轴位由车厢的位置、朝向和下列三个参数近似。每个虚拟轮对跨过接头时播放一次，正反向均可。车速改变敲击间隔，单次敲击以 90 km/h 为原调，音高倍率限制在 0.75–1.5。接头首版按等距生成。没有读取线路的实际接缝、道岔信息或车辆模型的轮距。这一层独立于牵引电机的音量校准。

客户端首次运行后，可在实例的 `minecraft/config/create_vvvf_simulator-client.toml` 编辑以下段，退出游戏后修改并重新启动：

```toml
[rail_joints]
joint_spacing_blocks = 25.0
axle_spacing_blocks = 2.0
bogey_spacing_blocks = 14.0
```

本机调试命令 `/railjointdebug 1`、`2`、`3` 选择固定采样，`off` 静音；中文入口为 `/撞轨音调试`。切换在下一次跨接头时可听，重启客户端默认选 1。配置和试听选择均由客户端处理。

三个单击均裁自 craigsmith 发布的 [R16-20-Train Wheels Clacking.wav](https://freesound.org/people/craigsmith/sounds/480813/)（CC0），来源为公开高品质预览。1、2、3 的起点分别为 44.662、34.489、8.038 秒，各保留 135、125、155 毫秒，经过滤波、淡化和电平调整。成品位于本目录 `src/main/resources/assets/niijima_rail_audio/sounds/`。触发参考 [openBVE 的轮轴过岔音与运行声](https://openbve-project.net/documentation/HTML/train_sound_cfg.html)。

隔离验证覆盖正反向、停车、坐标跳变、参数变化、同 tick 内的播放时机、三个调试选择与关闭。已核对成品 JAR 的声音清单和 Ogg 解码。实际游戏内听感待试听。

### 固定轮轨节奏 · test0131（pack-id 128，1.2.1-niijima.6）

从此版起，每列车对当前听者只播放一条「咔咔—小空—咔咔—大空」循环。车速控制循环推进，停车时暂停。附近车厢只提供移动量和发声位置，车厢数量、序号、轴数、几何和转向架样式均不参与排拍。原有采样切换与关闭命令沿用。

在原客户端 TOML 的 `[rail_joints]` 中，`joint_spacing_blocks` 给出一个完整循环所需的行驶距离，默认 25 格。`axle_spacing_blocks` 给出同一对敲击内的间隔，默认 2 格。`coupler_bogey_spacing_blocks`（新增，默认 4）和 `bogey_spacing_blocks`（默认 14）给出两对敲击起点之间短、长间隔的相对比例。四次敲击默认落在循环的 0、2、5.56、7.56 格处，再在第 25 格开始下一轮。极端配置下，同对间隔上限是较短组间距的一半，以保留双击分组。

隔离验证对比一节及十节车厢，覆盖不规则间距、最近车厢切换、倒车、不同更新顺序与采样选择；相同车速下四拍时序一致。另验证停车续播及间距修改。游戏内听感待试听。

### 转向架连线声源 · 1.2.1-niijima.11（2026-11-28）

客户端按编组顺序连接同一维度内已加载车厢的前后转向架，包括相邻车厢之间的连接段。单转向架按一个点处理，缺失车厢或传送门截断处断开连线。每个客户端按监听者位置求每列车的最近点，每游戏刻复用。Create 默认行驶声和原版手动鸣笛使用该点，鸣笛的起收音和持续音均随之定位。Create 音色和 VVVF 音色沿用 test0134 的播放分工。

VVVF 牵引声按最近距离计算近场和远场增益；各车厢的音量贡献不再相加。左右直达声按监听方向分配，混响尾音保留原有混合方式。阪急走行录音保留立体声，以同一点计算声像和原有的 32 格衰减。车速、节奏取自速度同步或车厢自身位移。旧接头调试采样也从最近点播放。

Forge 成品已重映射。用 Mixin 0.8.5 实际变换 Create 0.5.1.j 的 CarriageSounds，确认方向与距离两处注入均命中；离线测试覆盖长车厢中段、两端外侧、重合锚点、斜坡、车厢间隙、录音左右与居中声道及停车静音。现场听感待游戏内验收。
