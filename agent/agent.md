# Agent 视频交付规则

用户确认日期：2026-10-10。

处理和输出背景视频时，遵循以下要求：

1. **沿用原有命名方式**：`bg-video-编号-曲名.mp4`。曲名使用连续的小写英文或罗马字，不添加空格或词间连字符；编号沿用现有补零形式，例如 `03`、`29`。
2. **顺延编号**：交付前检查最新视频目录和已分配但尚未上线的编号，从最大已用编号继续递增，不从头编号、不覆盖或重复使用已分配编号。
3. **单独整理可复制成品**：把本批次最终验收通过的视频放进独立文件夹，方便用户直接复制。该文件夹只包含要交付的 MP4，不混入原始下载、旧版、日志、统计或脚本。
4. **核对交付副本**：复制后验证文件内容与已验收成品一致，在回复中给出交付文件夹路径和最终文件名。
5. **记录编号分配**：将本批次文件名、交付位置及是否已部署记录到对应专题文档，供下一次制作继续编号。
