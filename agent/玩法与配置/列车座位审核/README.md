# 列车座位审核

基线为本机已安装的 1.6.test0119（pack-id 116），2026-11-28。打开 `public/index.html` 即可离线审核。格子使用预先渲染的 200 × 200 PNG，界面和图像均无需联网。用下列命令启动本机服务后，使用 [浏览器审核页](http://127.0.0.1:18769/) 可把快照导出到固定目录。

```shell
python serve.py --port 18769 --exports <导出目录>
```

- 单击查看，Ctrl 单击增减选择，Shift 单击选择一段，拖动可框选。在格子区按 Ctrl+A 选中当前筛选结果，然后可在详情里批量更改状态或备注。Alt 单击在已选与排除间切换。

- 草稿保存在当前浏览器。导出快照包含全部 506 项的方块 ID、状态和备注。在服务模式下每次导出生成独立文件，新浏览器首次访问时读回最近导出。离线 HTML 使用浏览器下载。把选择写回游戏标签需另行执行。

优先可审 352 个常规新增座具。方块小镇有 297 项，即 344 个明确坐点扣除 44 辆自行车、1 个马桶及已经配置的 2 件常规家具；森罗厨房有 23 项；森罗酒馆有 32 项。玩家选择前，所有新增候选均保留待审。

审查其他模组时，Simple Planes 的座椅升级、Automobility 的后座是载具附件，Create Big Cannons 的炮闩使用专门的操作员交互；这些均未作为装饰座具收录。东方女仆的自定义椅子实体与该模组 8 个方块分开。嵌套实体、仅由代码生成且没有静态资源的方块、玩家服务器另加的数据包仍可能有遗漏。

TrainResync 的 `ContraptionSeatMixin` 仅在装配时把符合条件的方块坐标写入 Create 的座位列表。`AbstractContraptionEntity.handlePlayerInteraction` 随后按坐标找席位。上游家具的 `sit_pos` 有助于发现候选，标签本身不带这个偏移量。高脚凳、自行车、跨方块家具和多部件床的列车坐姿及座位数尚需实机试坐。

## 重新生成

```shell
python -m pip install Pillow numpy
python prepare.py <已安装实例的minecraft目录> <minecraft-1.20.1-client.jar> public
```

从方块模型与纹理生成正交预览，优先取单个未拼接家具的物品模型所引用的方块几何，再回退到方块状态模型。原版床按客户端 BedRenderer 的床头、床尾和床腿几何取实体纹理；东方女仆读取随包提供的 Bedrock 模型，女仆床取白色款。预览展示静态外观，游戏中的拼接、染色、动画和光照会有差别。界面中的模组名、Interiors 的原生继承判定和东方女仆交互证据按本基线核过，升级时复核。
