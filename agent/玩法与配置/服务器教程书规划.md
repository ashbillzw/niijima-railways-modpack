# 服务器教程书规划

收录本服独有的功能，以及本服配置明显改变了玩法的内容，例如受电弓的使用。模组的常规玩法沿用原教程。开篇从「加入服务器」开始，之后衔接其他教程书的获取入口。

## 加入服务器

欢迎加入！请加交流群：QQ **549428882**。初次游玩时（首 30 分钟），需要一位老玩家在线并输入 `/老带新`，或请联系管理员调整生存模式直接入服。

这是因为我们希望老玩家提供一些「老带新」，方便新玩家熟悉服务器，也避免出现「熊孩子」等问题。

## 提供担保

输入 `/老带新 <玩家名>` 来为新玩家提供担保。请帮助新玩家熟悉下服务器吧！

## 实现与验收约定（编写用）

2026-11-18 选定：启用担保的服务器上，新人首次以观察者模式入服时，自动打开「加入服务器」条目。条目做好后，使用 Patchouli 1.20.1-85 的服务端 `openBookEntry` 接口接入。用新号实测登录加载画面退场后能看到指定条目，关闭后重新登录不会再次弹出。
