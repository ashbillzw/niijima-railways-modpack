# 服务器教程书规划

收录本服独有的功能，以及本服配置明显改变了玩法的内容，例如受电弓的使用。模组的常规玩法沿用原教程。开篇依次为「加入服务器」「提供担保」「模组教程书」。

## 加入服务器

欢迎加入！请加交流群：QQ **549428882。**初次游玩时（首30分钟），需要一位老玩家在线并输入 `/老带新`，或请联系管理员调整生存模式直接入服。

这是因为我们希望老玩家提供一些「老带新」，方便熟悉服务器，也避免出现「熊孩子」等问题。

本服没有什么过多的规则，只要尊重其他玩家，不要故意破坏就行。最重要的是玩得开心！

## 提供担保

输入 `/老带新 <玩家名>` 来为新玩家提供担保。请帮助新玩家熟悉下服务器吧！

### 编写依据

零散配方改动只在 JEI 查询。

2026-11-19 选定在书里按用途放外链。「关于 FTB 地图与领地」放乘换案内、三维地图和主服轨道实况，分别链接到 `https://mc1.ashbill.com:25572/v3/` 的 `?tab=rail-network`、`?tab=bluemap` 和 `?tab=create-cn-rail-map`；乘换案内跟随默认现行图。「加入服务器」的交流群号链接到现有网站底栏使用的 QQ 群邀请；遇到问题时的反馈链接沿用网站导航的 `/v3/events/feedback-v1.6/`。书页使用完整 HTTPS 地址。

本包 Patchouli 1.20.1-85 Forge 的外链页 `patchouli:link` 调用 `GuiBook.openWebLink`，先显示 Minecraft 的网址确认框，玩家同意后交给操作系统打开，并恢复原书页。已核对包内版本的字节码，实际点选留待做书时验收。

货币与送餐对照[美团接单机制](美团接单小游戏机制.md)和两服共享配置。铁路参数和领地额度来自两个世界的 `serverconfig`；座位、接触网、领地交互名单和燃料以包内 KubeJS 标签与配方为准。[功能台账及其他教程书](../整合包自定义功能.md)和[玩家说明审计](../模组管理/自定义功能玩家说明审计-20261106.md)可按条目查原文。锅的具体操作按[炼药锅反馈](../物品整合/炼药锅测试反馈-20261019.md)的最新复测结果取舍。

书写的是玩家可用的玩法。管理员诊断、后台存档保护、透明防崩修复沿用运维文档；彩蛋商店和其他创作奖励目前是构想，等开放后再写。历史文案审阅中选定保留的礼包措辞、龙蛋彩蛋沿用原决定。

## 实现与验收约定（编写用）

2026-11-19 选定：游戏内书页用 Patchouli 的 `$(k:...)` 显示玩家模型和动作轮盘的实际绑键，对应 `key.yes_steve_model.player_model.desc` 和 `key.yes_steve_model.animation_roulette.desc`。验收时检查默认 Alt＋Y 的修饰键显示，再分别改键并重新打开书页核对。

2026-11-18 选定：启用担保的服务器上，新人首次以观察者模式入服时，自动打开「加入服务器」条目。条目做好后，使用 Patchouli 1.20.1-85 的服务端 `openBookEntry` 接口接入。用新号实测登录加载画面退场后能看到指定条目，关闭后重新登录不会再次弹出。
