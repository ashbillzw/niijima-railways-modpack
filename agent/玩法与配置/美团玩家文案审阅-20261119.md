# 美团玩家文案

2026-11-19。以 TrainResync main 的 `1bf0c4b` 为基线整理。自 `1.6.0.bn` 起，取消链接、点餐广播、选单首行和选单点击操作使用下列中文指令，已核对本机构建的 JAR。花括号表示动态内容。

美团指令已注册中文、拼音、英文三套入口。内置提示默认展示中文，可点击操作也使用对应的中文指令。

中文入口随 `1.6.test0079`（pack-id 76）交付。跨维度查单、接单与取消点餐随 `1.6.test0080`（TrainResync `1.6.0.bo`、`master` 渠道 pack-id 77）交付。离线构建和已有美团规则测试通过，游戏内跨维度操作待实测。

## 点餐与取消

| 触发 | 玩家看到的文字 |
|---|---|
| 点餐成功，或更新尚未被接单的收餐位置 | `【美团】已成功下单，定位 {X} {Y} {Z}，等待接单。` |
| 同上，但点餐者另有正在配送的订单 | `【美团】（{数量} 单 送货中）已成功下单，定位 {X} {Y} {Z}，等待接单。` |
| 上面两种成功消息的下一行，黄色，可点击取消 | `/美团 取消点餐` |
| 找不到可放箱子的位置 | `【美团】外卖箱放置空间不足！` |
| 新点餐，其他符合广播条件的在线玩家收到 | `【美团】收到{点餐玩家}的点餐订单！接单：/美团 接单。` |
| 成功取消待接单 | `【美团】已取消点餐。` |
| 没有可取消的点餐 | `【美团】没有可以取消的点餐。` |
| 没有可取消的点餐，但有订单正在配送 | `【美团】（{数量} 单 送货中）没有可以取消的点餐。` |

## 查单与接单

| 触发 | 玩家看到的文字 |
|---|---|
| 有可接订单，显示列表首行 | `【美团】当前可接取订单如下！用/美团 接单 <编号>接单！` |
| 没有可接订单 | `【美团】暂无可接订单。` |
| 接单时原选单已变化 | `【美团】选单发生变化，请重新选择。` |
| 接单成功，随后逐行列出餐品 | `【美团】已接单！定位 {X} {Y} {Z}` |
| 配送中再次查单或尝试接另一单，随后逐行列出餐品 | `【美团】当前还有未完成订单！定位 {X} {Y} {Z}` |
| 玩家单被接，在线点餐者收到 | `【美团】订单已被{配送员}接单！` |

**列表中的每一行**都可点击接单，执行 `/美团 接单 {编号}`。基础格式如下：

```text
{编号} | {点餐者} | {基础金额}元 → {报酬}元 | {物品名} ×{数量} | {距离}米
```

- 点餐者显示玩家名，动物单显示「动物名-四位数字」。距离按水平 X/Z 计算，四舍五入为整数。
- 基础金额与报酬之间可以依次出现以下片段：` → {小计}元`（小计有变化）、` ×{倍率}火爆`、` ×{倍率}远单`、` ×{倍率}玩家单`、` ×{倍率}活动期间`。只显示满足条件的片段。
- 多种餐品之间用空格分隔。单品加成紧跟该物品数量，格式为 `（{加成名}×{倍率}）`，每个非 1 倍的加成各列一次。整蛊物品名用金色粗体。含加成的金额达到基础金额两倍时，最终报酬用浅紫色粗体。

**接单后或再次查询的餐品明细**每种物品独占一行：

```text
{模组名}：{物品名}（{物品ID}）×{数量}
```

原版物品直接从物品名开始。模组名的内置中文取值为「悠然一派」「烧烤乐事」「机械动力」「机械动力：中央厨房」「机械动力：工艺与附加」「农夫乐事」「水果乐事」「森罗物语：厨房」「森罗酒馆」「自然之灵」「那不勒斯风味」「独特风味」「锦致装饰」。其他模组使用模组显示名，取不到时用命名空间。

## 送达、超时与错误

| 触发 | 玩家看到的文字 |
|---|---|
| 没有配送单时执行送达 | `【美团】当前没有配送中的订单。` |
| 距离过远 | `【美团】距离送达定位过远！（送达定位：{X} {Y} {Z}）` |
| 可交付餐品不足 | `【美团】背包中没有足够的餐品！` |
| 成功送达，配送员收到 | `【美团】成功送达！报酬{金额}元已发放。` |
| 成功送达，在线点餐者收到 | `【美团】您的外卖已由{配送员}送达！（外卖员：{配送员}，位置：{X} {Y} {Z}）` |
| 超时，在线配送员收到 | `【美团】当前订单已超时失败。` |
| 超时，在线点餐者收到 | `【美团】您的外卖送货失败！（外卖员：{配送员}）` |
| 在主世界外点餐或执行送达 | `【美团】只能在主世界送餐！` |
| 执行异常，或后台生成配送位置遇到异常 | `【美团】暂时无法完成操作，请稍后重试。` |

## 核对结果

- 自 `1.6.0.bo` 起，各维度均可查单、接单和取消待接点餐。距离和远单倍率都按主世界格数计算：下界用玩家 X/Z × 8，末地用玩家的主世界重生点，没有个人主世界重生点时用主世界出生点。新动物单也围绕同一个位置在主世界生成。
- 配送中再接单会显示「当前还有未完成订单！」以及现有餐单和坐标。接单成功时没有「接单后无法取消」这一句。取消点餐只处理点餐者尚未被接的单。
- 无效编号或缺少预览时重新显示选单，正常生成动物单期间没有等待文案。
- 送达检查遍历玩家主物品栏（含快捷栏）及副手，可从多格凑齐数量。当前不会递归读取模组背包、潜影盒等容器内部的餐品。
