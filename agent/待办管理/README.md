# 整合包待办管理页

在此目录运行 `python -B server.py`，打开 [本机管理页](http://127.0.0.1:18768/)。仅需 Python 3，只监听本机。关闭进程即可停用。

- 点击左侧类别查看卡片。把卡片拖到类别名即可移动，卡片随目的类别换色。拖到同类卡片上方可排序，拖到列表末尾的留白可排到最后。
- 点击卡片文字可查看、编辑完整 Markdown，也可用「类别」选择目标后一起保存。键盘或触屏可用同一入口移动卡片。
- 勾选即在 [todo-list.md](../todo-list.md) 标记 `[x]`。再次点击可撤销。agent 整理时将确认完成的条目移入文件末尾的历史区，移出当前队列。
- 清单直接取自 Markdown 中首个 `<details>` 之前的分类标题和顶层勾选项；续行、子项缩进两个空格。历史区及非任务段落原样保留。页面与 agent 共用此文件。其他窗口已改动清单时，先保留需要的草稿，刷新后再应用。
- 分类思维导图是标注日期的快照。管理页每次打开都读取当前清单。
