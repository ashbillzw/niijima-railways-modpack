### 机械动力：父节点与独立入口

- **机械动力兼容 → 动力泵交互／机械手交互**。动力泵包含通过管道泵入、泵出，仍受液体映射、容量和数据一致性约束。不同药水不能通过泵直接混合。燃烧室留在热源分枝，不重复画跨图长线。
- Deployer 的官方中文资源键 `block.create.deployer` 为“机械手”。本机只读 Create 0.5.1.j 源码 `DeployerHandler.java` 的使用模式调用 `ForgeHooks.onRightClickBlock`，随后走方块／物品使用流程；helper `MilkIntegration.interact` 监听该事件，没有排除 `FakePlayer`，因此现有右键处理具有入口。
- 上述是代码路径证据，**不等于所有机械手物品、交互取消及容器返还已验收**。尤其机械手事件之后仍有后续使用逻辑，实际需要核对是否二次执行；本轮仅画图，未改兼容代码。

### 帽架彩蛋

锦致装饰 `HatStandEntity.setSkibidiIfInCauldron` 检查脚下方块是否为 `AbstractCauldronBlock`，随后进入名为 `Skibidi` 的动画状态，不检查锅内液体，不是配方。该版本站立状态约每 100 tick 有 20% 的随机机会检查，动画计时为 160 tick；这里只记录字节码逻辑，没有游戏操作复现。堆肥桶等其他触发对象不属于本图范围。

证据保存在仓库外：`cauldron-audit-20261017/javap/net.mehvahdjukaar.supplementaries.common.entities.HatStandEntity.txt`（1376 行起）及 `sourceref-do-not-modify/Create/`。原版来源为 `sourceref-do-not-modify/1.20.1-decompiled/` 的 `CauldronInteraction`、`CauldronBlock`、`LayeredCauldronBlock` 等；均位于当前独立工作目录。

### 完整性与当前可用性的边界

本图尽量覆盖当前已核对的**交互类别**，不逐条重复每种颜色、药水 NBT、九种奶昔、各水果及动态合成配方。音效／游戏事件／统计、存档重载、无效输入保护属于已有功能的回归条件，放在测试表，不各画一条“新玩法”。冻结动画属于显示回归；WorldEdit／旧格式映射／注册基础设施不是独立生存交互。未安装模组的兼容代码不计入当前玩法。

龙头仍受原有禁用项和配置控制；节点表示兼容路径，不能据此视为已启用。已有失败／待测状态继续以测试反馈为准，图不是“全部已通过”清单。未来新增模组、注册容器或配方可能扩展行为，不能仅凭静态图保证运行时所有组合已穷尽。
