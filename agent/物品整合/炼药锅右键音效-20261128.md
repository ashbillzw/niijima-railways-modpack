# 炼药锅右键音效

## 1.6.0.co · 成功右键的音效补齐

| 操作 | 操作者和附近玩家听到的音效 |
| --- | --- |
| 柠檬片起锅、加第一份水果、续加同种水果、倒入瓶装果酱、加糖、加黏液球 | 成功改锅后播放一次水果乐事给这一步登记的音效。1.1.3 上述步骤均为水花声 `entity.generic.splash`，音量 0.65。 |
| 用瓶取果酱、用碗取果冻 | 沿用原来的一次 `item.bottle.fill`，广播也包含动手的玩家。 |
| 清洗皮革、旗帜、潜影盒，或使用锦致装饰洗地图标记 | 注册的清洗回调成功后，播放一次水花声。统一清水锅与原版水锅均适用。 |
| 首次让可发光的锅液发光 | 从未发光变为发光时，播放一次 `block.bubble_column.bubble_pop`；往已经发光的锅里再点一下不会重播。 |

仅复用整合包已有声音。水果加工条件、返瓶、取成品以及桶瓶注取、染色、混药的既有反馈沿用原逻辑。Gradle build 通过。用成品 JAR 中的 Mixin 和 refmap 对水果乐事 1.1.3 及 Minecraft 1.20.1 的发行类做了隔离织入验证，并核查成功、失败和客户端分支。普通包与本地测试包已构建，启动器登记为 1.6.test0120（pack-id 117）。实际游戏听感及两位玩家同时试听待验。

## 1.6.0.cn · 修改前的审计

2026-11-28，按本地 1.6 开发包核对。范围为玩家手持物品直接右键锅的成功交互。锅底热源、随机沸腾、物品实体落锅和发射器有各自的发声路径。下表记录代码发出的声音，未进游戏试听。原版音效 ID 省略 `minecraft:`。

## 水果果冻的制作顺序

| 右键操作 | 成功条件 | 操作者听到的交互声 | 附近其他玩家 |
| --- | --- | --- | --- |
| 用水桶或水瓶加水 | 统一锅有空间容纳一整份，分别加入 1000 或 250 mB | `item.bucket.empty` 或 `item.bottle.empty` | 同左 |
| 加柠檬片 | 满水锅 → 柠檬水锅 | 无 | 无 |
| 加第一份水果 | 柠檬水锅有有效热源 → 对应水果锅 | 无 | 无 |
| 续加同种水果 | 有热源，锅内还能接受该份水果 | 无 | 无 |
| 加糖 | 水果投料已满，有热源 → 果酱锅 | 无 | 无 |
| 加黏液球 | 果酱锅有热源 → 对应果冻锅，保留剩余份数 | 无 | 无 |
| 空碗取果冻 | 果冻锅至少剩一份 | 无 | `item.bottle.fill` |
| 空玻璃瓶取果酱（支线） | 果酱锅至少剩一份 | 无 | `item.bottle.fill` |
| 倒入瓶装果酱（另一条投料路线） | 满水锅起锅，或同味水果锅能接受这一份。不要求热源 | 无 | 无 |

水果乐事 1.1.3 的 `FDCauldrons.init` 为前述投料注册了 `entity.generic.splash`，但 `FDCauldronInteraction.interact` 只在主产物 `result` 非空时调用播放。投料改锅状态，返还的空瓶也走单独的余物分支，两种情况都跳过播放。取果酱和取果冻的主产物非空，两者都使用装瓶声；调用只在服务端执行，同时把操作者传为排除的玩家。原版 `PlayerList.broadcast` 跳过该玩家。TrainResync 的该处 Mixin 只调整热源判断和成功时挥手。加热时听到的锅内沸腾声是随机环境反馈。

## 其他已核对的右键操作

| 音效 | 触发条件 |
| --- | --- |
| `item.bucket.empty` / `item.bucket.fill` | 水或牛奶用桶注入／取出，统一锅每桶 1000 mB。自然之灵用奶酪桶装锅／从成熟奶酪锅用空桶取奶酪也走这对声音。 |
| `item.bucket.empty_lava` / `item.bucket.fill_lava` | 岩浆桶注入／空桶取出一桶岩浆。 |
| `item.bucket.empty_powder_snow` / `item.bucket.fill_powder_snow` | 细雪桶装锅／空桶从满细雪锅取出。 |
| `item.bottle.empty` / `item.bottle.fill` | 统一锅用瓶注取清水、牛奶、奶昔，每次 250 mB。满统一奶锅加制酪材料启动熟成、加对应冰淇淋制奶昔，也各播一次 `item.bottle.empty`。 |
| 登记容器的倒空声，默认 `item.bottle.empty` | 走 Moonlight 软流体容器的成功注取，如注册的蜂蜜、药水、饮品。2.16.35 的 `drainItem` 和 `fillItem` 发声分支都读 `Category.getEmptySound()`；若容器另配音效，以容器定义为准。 |
| `item.dye.use` 和 `item.bucket.empty` | 满水锅加染料制成染液，或给已有染液成功加入染料混色。一次操作使用两个声音。 |
| `item.bucket.empty` 或 `block.brewing_stand.brew` | Amendments 手持配方成功时比较输入与输出的软流体类型。同类型播较高音调的倒桶声，类型改变播较低音调的酿造声。包括走此入口的锅内合成、染液给物品染色、药水浸箭、发光水浸箭。剩余量变化和流体类型变化是两项判定。 |
| `entity.generic.extinguish_fire` / `entity.generic.explode` | 混药触发效果上限警告或相斥药效反应时有熄火声；已有上限数量的效果后继续新增效果，触发爆锅时有爆炸声。当前上限 8。 |
| `block.bubble_column.bubble_pop` / `entity.cow.milk` | 自然之灵原生牛奶锅分支：给尚未开始熟成的原生奶锅加入制酪材料／在允许取奶的状态用空桶取奶。通常从统一空锅新倒入的牛奶走上面的统一锅逻辑。 |
| 无专用成功音 | 用水洗皮革染色、旗帜图案、潜影盒颜色；向允许发光的锅液第一次加入发光材料。扣水、挥手、方块变化和振动游戏事件可以正常发生。锦致装饰洗地图自定义标记的注册回调本身也没有播放调用。 |

核对材料为包内 TrainResync 1.6.0.cn 对应的炼药锅实现、水果乐事 1.1.3、Amendments 2.2.3、Moonlight 2.16.35 和 1.20.1 游戏逻辑。容器行按注册规则归纳，不逐个枚举物品和资源包实际播放的采样。依赖代码可对照 [水果交互](https://github.com/Minecraft-LightLand/FruitsDelight/blob/1.20/src/main/java/dev/xkmc/fruitsdelight/content/cauldrons/FDCauldronInteraction.java) 和 [水果锅注册](https://github.com/Minecraft-LightLand/FruitsDelight/blob/1.20/src/main/java/dev/xkmc/fruitsdelight/init/food/FDCauldrons.java)。
