# 特殊重复审查2

2026-11-26。以下六项来自开发包 109 个启用模组 JAR 的配方和标签，并已对照包内 KubeJS、OEI 与燃料配置。六项均待游戏内核实。审核时可用 F3+H 查看物品 ID，并记录测试包版本：________。

### 1. 工业铁：同一枚铁锭能否产出 1 枚或 18 枚工业铁锭？

| 各投入 1 枚普通铁锭 | 静态配方推算 |
| --- | --- |
| Create Deco 加热压实 | 1 枚工业铁锭 |
| Create 切石机 → 工作台拆块 | 2 个工业铁块，每块拆成 9 枚工业铁锭，共 18 枚 |

在切石机里先确认普通铁锭能否选出 `create:industrial_iron_block`，再实际拆块。另用一枚普通铁锭加热压实，比对两条路线的数量和最终 ID 是否均为 `createdeco:industrial_iron_ingot`。若有一步走不通，记下具体步骤。

配方核对点：Create 的切石配方是 `create:industrial_iron_block_from_ingots_iron_stonecutting`。Create Deco 提供的加热制块配方是 `create:industrial_iron_block_from_iron_ingots_stonecutting`，两者词序不同。拆块和加热制锭分别见 `createdeco:industrial_iron_ingot_from_industrial_iron_block`、`createdeco:compacting/industrial_iron_ingot`。

**实测结论：** 待核实

### 2. 面条：换砧板后，另一家的锅还收不收？

同一种 `forge:dough` 面团分别放上两家砧板。农夫乐事配方给 1 份生意面，森罗配方给 3 份生面条。农夫乐事的 5 道面食引用意面标签；森罗的牛肉面、热干面、羊肉烩面和乌冬面直接指定自家生面条。

选农夫乐事面汤和森罗牛肉面各做一轮：先用各自的面确认能出菜，再保持锅、汤底和配料相同，只交换面条，记录两个方向能否出菜。对应 ID 为 `farmersdelight:raw_pasta` 和 `kaleidoscope_cookery:raw_noodles`。

**实测结论：** 待核实

### 3. 培根与五花肉：通用猪肉配方与专用菜是否接受同样的替换？

同一种原版生猪排，农夫乐事砧板配方切出 2 份生培根，森罗砧板配方切出 3 份生五花肉。两者都在 `forge:raw_pork` 内，熟制品也都在 `forge:cooked_pork` 内。

先用两种生肉各试一次接受 `forge:raw_pork` 的配方。再用各自的熟肉正常制作培根煎蛋和冷切火腿片，随后只交换熟肉。记录哪道菜接受替换，以及各砧板的实际产量。

**实测结论：** 待核实

### 4. 种子榨油：同种种子能得到哪些油，各自能用在哪里？

各取 1 份相同的 `forge:seeds` 种子。Crafts & Additions 压实配方给 100 mB `createaddition:seed_oil`；森罗石磨配方给 1 个 `kaleidoscope_cookery:oil`。森罗油脂另有动物来源。

核对两个产物与数量。分别查看种子油能否供包内飞机或列车作燃料、油脂能否制作酥油茶茶包；再查 JEI 用途和容器配方，记录是否有让一条路线的产物进入另一条路线的转换方式。

**实测结论：** 待核实

### 5. 金属走道：两套走道是否都可制作，放置后有什么差别？

Create Deco 和 Design n’ Decor 的配方中都有铁、铜、黄铜和锌走道。取铁走道作对照：切石机的两项配方各用 1 枚铁锭出 4 个，结果分别为 `createdeco:iron_catwalk` 与 `design_decor:iron_catwalk`。

确认切石机能否实际取出两种结果。把两种走道并排放置，比较外观、连接效果及配套栏杆；其余三种金属在 JEI 中核对两家是否都有配方。

**实测结论：** 待核实

### 6. 金属窗：同样两扇黄铜窗，是否分别消耗 3 锭和 3 粒？

Create Deco 与 Create Framed 都有金属窗及窗格。黄铜窗的两张配方分别用 3 黄铜锭或 3 黄铜粒，搭配无色玻璃，各出 2 扇。结果分别为 `createdeco:brass_window` 与 `createframed:brass_window`。

用同一种受两张配方接受的玻璃各合成一次，记录消耗与产量。将两种窗并排放置，比较窗框与拼接外观，再查各自能加工成哪些窗格。

**实测结论：** 待核实
