## 选稿依据

以下为 11 月 18 日北京时间，对应历史设计对话 ID 01a09b23-92c8-76a2-a672-9a47b28f436a。

- 01:16 要求每个服各自显示玩家数。01:33 选按钮方案 1，要求文案「自动选择节点」和普通右箭头。01:36 要求右上只留小号单人游戏按钮。
