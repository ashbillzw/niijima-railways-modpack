## 立绘的精确边界

1. 原图抠图使用 SkyTNT/anime-segmentation 的 `isnetis.onnx` 预测 alpha，再修正下部蕾丝的背景残留；没有使用生成模型重画 RGB。抠图成品 `character-final-alpha.png` 已核对 RGB 与原图一致，`event-character.png` 为项目保留的未补全副本。
2. 第一份扩图 `character-outpaint-generated.png` 是整幅生成候选，不能宣称原像素不变。用户喜欢该版自然的搭扣鞋，明确不再重新生成。
3. 早期 `character-outpaint-locked.png` 将原画布所有 RGBA 硬贴回去，虽然验证了原像素不变，却把原图被截断的靴面贴回搭扣鞋附近，产生不自然接缝；此文件没有用于当前网页。
4. 早期 `event-character-complete.png` 来自 `character-first-shoe-candidate.png`：原图坐标 y=0–1639、x=0–1023 的 RGBA 完全保留；y=1640–1699 做过渡，下面使用第一份生成结果；右侧新增部分也来自该生成结果。**因此当前网页并非全原画布逐像素锁定版**。禁止把它与纯生成候选或严格锁定试验混称。
5. 后来的第二次生成实际上只生成鞋部局部，用户认为不如第一版自然，已弃用；不能称作第二份完整立绘。

工具脚本位于仓库外 `工具/anime-cutout/`：`extract_alpha.py`、`lower_detail.py`、`integrate_assets.py`、`lock_outpaint.py`、`first_shoe_candidate.py`。原始生成图和两次生成层的对齐记录保留在源目录。

## 丝带文字与响应式

- 主标题桌面字号上限 104 px，副标题为其 0.57 倍；平板和手机分别调整。
- 丝带使用真实 SVG 文字，初始从 textPath 读取每个字的原点和旋转角，然后固定为同一 text 对象中的 tspan。只在字自身的竖直轴上移动，不重新调整字距、路径或角度。
- 当前「试／期／间」向下偏移为 3／6／9 个 SVG 单位，其他字符为 0。调整入口在 `dist/assets/event.js` 的 offsets；字体、字号、原路径不变时，其余字的位置和角度不变。
- 设置 `user-select:all`，浏览器实际选中文本为 `v1.6 测试期间`，没有额外空格。字体使用现有系统字体栈，不再把文字烧进素材图。
- 超宽屏将已补全角色锚在内容区附近，避免沿 viewport 放大后裁掉脚部；桌面角色与表单轻微交错。窄屏角色在上部，表单通栏。装饰不拦截表单点击。

## 开源扩图工具调查（此前记录）

2026-11-06 核对官方仓库和说明。没有可靠的扩图用户数排行榜；GitHub stars 仅是关注度代理。在核对的三项中，[ComfyUI](https://github.com/Comfy-Org/ComfyUI) 约 13.3 万 stars，GPL-3.0；[InvokeAI](https://github.com/invoke-ai/InvokeAI) 约 2.9 万，主体 Apache-2.0；[Krita AI Diffusion](https://github.com/Acly/krita-ai-diffusion) 约 1.08 万，GPL-3.0。工具的许可不等于所有可加载模型都使用相同许可。

ComfyUI 有 [Pad Image for Outpainting](https://docs.comfy.org/tutorials/basic/outpaint)，可控制扩展范围、mask 和 feathering；InvokeAI 有绘画式 Unified Canvas；Krita 插件提供选区生成、图层与绘画整合。对当前插画的小范围补全，更倾向 Krita 插件配合可控蒙版；若要可重复的自动处理，则 ComfyUI 更合适。仅完成调查，未安装这些工具、未下载生成模型，未再次生成角色。

有明确蒙版和合成节点，可以强制保留不编辑区域；但蒙版边界仍需处理，不能据此承诺接缝完美。当前会话 imagegen 接口没有单独的 mask／像素锁定参数，不应把提示词约束等同硬约束。
